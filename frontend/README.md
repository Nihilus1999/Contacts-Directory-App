# 🖥️ Contacts App — Frontend

Frontend de la aplicación **Contacts**, desarrollada con **React** y **Next.js 16 App Router**, utilizando **Material UI (MUI)** para la interfaz de usuario.  
Esta aplicación permite **gestionar contactos de forma intuitiva**, con funcionalidades de búsqueda, validación de formularios, modales de confirmación y una experiencia de usuario moderna sobre un fondo oscuro estilizado.

---

## 🚀 Tecnologías utilizadas

- React 19
- Next.js (App Router)
- Material UI (MUI)
- TypeScript
- Axios
- React Hook Form

---

## 🛠️ Instalación del frontend

1. Instalar las dependencias necesarias:

```
npm install
```

2. Puede utilizar la misma variable de entorno cargada en el repo, ahi ya se encuentra la url con la conexion al backend

3. Ejecuta el siguiente scripts personalizado para correr el backend en desarrollo

```
npm run frontend
```
