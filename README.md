# 📇 Contacts Directory App

Aplicación web para la **gestión de contactos**, que permite crear, consultar, actualizar, eliminar y buscar contactos de forma rápida y sencilla.

El proyecto está dividido en dos partes independientes:
- **Backend**: API REST desarrollada con Node.js, Express y PostgreSQL.
- **Frontend**: Aplicación web desarrollada con React para consumir la API y ofrecer una interfaz amigable al usuario.

## 🚀 Cómo empezar

Cada parte del proyecto cuenta con su propia documentación:

- 📌 **Backend**  
  Dentro de la carpeta `backend/` encontrarás un archivo `README.md` con:
  - Pasos de instalación
  - Configuración de variables de entorno

- 🎨 **Frontend**  
  Dentro de la carpeta `frontend/` encontrarás un archivo `README.md` con:
  - Pasos de instalación
  - Configuración de entorno
  - Forma de ejecutar la aplicación
